# HLS Recorder

Приложение Windows на Electron для обнаружения HLS-трансляций в браузере и сохранения видео в MKV без перекодирования. Расширение **HLS Sniffer → Electron** передаёт плейлисты приложению через локальный API на порту `3131`.

## Возможности

- Плитки трансляций, превью, прогресс записи, светлая и тёмная темы.
- Адаптивная сетка на 2–4 колонки и собственная панель окна.
- Объединение вариантов качества одной трансляции.
- Выбор варианта с максимальным битрейтом из главного HLS-плейлиста.
- Обработка LL-HLS, MP4-инициализации и адресов сегментов Stripchat, наблюдаемых в браузере.
- Повторная запись и корректное завершение MKV кнопкой «Стоп».

## Запуск из исходников

1. Установите Node.js и выполните `npm ci` в папке проекта.
2. Поместите Windows-бинарник `ffmpeg.exe` в `bin/`. Для тестов также нужен `ffprobe.exe`. Проверенная версия: FFmpeg `2025-12-14-git-3332b2db84`, full build от [Gyan](https://www.gyan.dev/ffmpeg/builds/). Бинарники не хранятся в Git.
3. В `chrome://extensions` включите режим разработчика, нажмите «Загрузить распакованное расширение» и выберите папку `extension/`.
4. Выполните `npm start`, затем откройте трансляцию в браузере.
5. Нажмите «Записать» в карточке. Файлы сохраняются в системную папку «Загрузки».

Для Stripchat браузер должен продолжать воспроизведение: приложение использует реальные адреса сегментов из расширения. При старте выбирается текущее качество браузера. Лучше использовать фиксированное качество: его переключение во время записи может прервать загрузку сегментов.

## Сборка Windows

```powershell
npm run dist
```

Установщик появится в `dist/`. Он включает FFmpeg и папку расширения в `<папка установки>/resources/extension`. Эту папку можно загрузить в Chrome как распакованное расширение. Расширение требуется установить отдельно; приложение не устанавливает его автоматически.

## Проверки

```powershell
node tests/hls.cjs
node tests/stream-sync.cjs
node tests/recording.cjs
```

Проверяются обработка плейлистов, доставка из расширения, группировка, восстановление карточек, запись через прокси и завершение MKV. Тест записи требует `bin/ffmpeg.exe` и `bin/ffprobe.exe`.

## Диагностика

Раскройте «Журнал событий» или нажмите «Копировать логи». Журнал также сохраняется в `%APPDATA%/electron-hls-recorder/recorder.log`. Логи могут содержать адреса с временными токенами; они исключены из Git.

Локальное состояние API: `http://localhost:3131/status`.
